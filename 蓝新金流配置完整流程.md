# 蓝新金流 (NewebPay) 配置指南

> 本文档记录了蓝新金流的标准配置方式，供后续新项目参考。

## 概述

本项目使用 Cloudflare Workers 作为后端，已完整集成蓝新金流（NewebPay）台湾第三方支付网关，支持信用卡、ATM转账、超商缴费等支付方式。

## 核心代码结构

### 1. 类型定义 (src/types/payment.ts)

```typescript
// 支付方式枚举
export enum PaymentMethod {
  CREDIT_CARD = 'credit_card',
  ATM = 'atm',
  CONVENIENCE_STORE = 'cvs',
  BARCODE = 'barcode'
}

// 蓝新金流配置
export interface NewebPayConfig {
  merchantId: string;
  hashKey: string;
  hashIV: string;
  apiUrl: string;
  version: string;
}

// 支付请求
export interface PaymentRequest {
  orderId: string;
  amount: number;          // 金额（分）
  currency: string;
  description: string;
  buyerEmail: string;
  paymentMethod: PaymentMethod;
  returnUrl: string;       // 支付完成跳转URL
  notifyUrl: string;       // 异步回调URL
}
```

### 2. 加密工具 (src/utils/crypto.ts)

蓝新金流使用 **AES-256-CBC** 加密 + **SHA256** 签名校验：

```typescript
// AES加密（NewebPay格式）
export async function aesEncrypt(data: string, key: string, iv: string): Promise<string>

// AES解密（NewebPay格式）
export async function aesDecrypt(encryptedData: string, key: string, iv: string): Promise<string>

// SHA256哈希
export async function sha256(data: string): Promise<string>
```

**关键要点**：
- 使用 **PKCS7 填充**（32字节块大小）
- 输出格式为 **Hex 字符串**（非 Base64）
- 密钥和 IV 必须是 **16或32位字符**

### 3. 蓝新适配器 (src/services/payment/newebpay.adapter.ts)

核心方法：

| 方法 | 功能 |
|------|------|
| `createPayment()` | 创建支付请求，生成加密表单 |
| `verifyCallback()` | 验证回调签名 |
| `parseCallback()` | 解析回调数据 |
| `refund()` | 处理退款请求 |

**TradeInfo 加密流程**：
1. 构建交易信息对象（包含 MerchantID, OrderNo, Amount 等）
2. 转换为 URL Query String 格式
3. 使用 AES-256-CBC 加密（HashKey + HashIV）
4. 生成 TradeSha：SHA256("HashKey={key}&{TradeInfo}&HashIV={iv}")

**支付方式代码映射**：
```typescript
CREDIT: 1  // 信用卡
VACC: 1    // ATM转账
CVS: 1     // 超商缴费
```

### 4. 支付路由 (src/routes/payment.ts)

API 端点：

| 端点 | 方法 | 功能 |
|------|------|------|
| `/api/payment/create` | POST | 创建支付请求 |
| `/api/payment/callback/:gateway` | POST | 接收支付回调 |
| `/api/payment/status/:orderId` | GET | 查询支付状态 |
| `/api/payment/refund` | POST | 处理退款 |

**创建支付请求示例**：
```typescript
POST /api/payment/create
{
  "orderId": "12345",
  "gateway": "newebpay",        // 或 "ecpay"
  "paymentMethod": "credit_card" // 或 "atm", "cvs"
}

// 响应
{
  "success": true,
  "transactionId": "txn_xxx",
  "formHtml": "<!DOCTYPE html>..."  // 自动提交的支付表单
}
```

## 支付流程

### 标准支付流程

```
┌─────────────┐     ┌──────────────┐     ┌─────────────┐     ┌─────────────┐
│   用户      │     │   前端       │     │   后端      │     │  蓝新金流    │
└──────┬──────┘     └──────┬───────┘     └──────┬──────┘     └──────┬──────┘
       │                   │                    │                    │
       │ 1.选择支付方式     │                    │                    │
       │──────────────────>│                    │                    │
       │                   │ 2.请求创建支付      │                    │
       │                   │───────────────────>│                    │
       │                   │                    │ 3.创建交易记录      │
       │                   │                    │────┐               │
       │                   │                    │<───┘               │
       │                   │                    │ 4.生成加密表单      │
       │                   │<───────────────────│                    │
       │ 5.返回HTML表单     │                    │                    │
       │<──────────────────│                    │                    │
       │ 6.自动提交到蓝新   │                    │                    │
       │─────────────────────────────────────────────────────────────>│
       │                   │                    │                    │
       │                   │                    │ 7.用户完成支付      │
       │                   │                    │<───────────────────│
       │                   │                    │ 8.异步回调通知      │
       │                   │                    │<───────────────────│
       │                   │                    │ 9.更新订单状态      │
       │                   │                    │────┐               │
       │                   │                    │<───┘               │
       │                   │                    │ 10.返回 1|OK       │
       │                   │                    │───────────────────>│
       │ 11.跳转回商家页面  │                    │                    │
       │<─────────────────────────────────────────────────────────────│
```

### 回调处理要点

1. **验证签名**：使用 TradeSha 验证回调数据完整性
2. **幂等性检查**：已处理成功的订单不再重复处理
3. **并发控制**：成功支付后取消该订单的其他待支付交易
4. **响应格式**：成功返回 `1|OK`，失败返回 `0|错误信息`

### 2. 支付流程前端实现

```tsx
// 创建支付请求
const createPayment = async (orderId: string, gateway: string, method: string) => {
  const response = await fetch('/api/payment/create', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ orderId, gateway, paymentMethod: method })
  });
  
  const data = await response.json();
  
  if (data.success && data.formHtml) {
    // 将表单插入页面并自动提交
    const div = document.createElement('div');
    div.innerHTML = data.formHtml;
    document.body.appendChild(div);
    
    // 表单会自动提交到蓝新金流
    const form = div.querySelector('form');
    if (form) form.submit();
  }
};
```

### 3. 支付返回页面

```tsx
// 处理蓝新金流返回
const handlePaymentReturn = () => {
  // 从 URL 获取支付结果参数
  const params = new URLSearchParams(window.location.search);
  const status = params.get('Status');
  
  if (status === 'SUCCESS') {
    // 支付成功，查询订单状态
    checkOrderStatus(orderId);
  } else {
    // 支付失败或取消
    showPaymentFailed();
  }
};
```

### 2. 数据库表结构

```sql
-- migrations/001_add_payment_tables.sql

-- 支付交易记录表
CREATE TABLE payment_transactions (
  id TEXT PRIMARY KEY,
  order_id TEXT NOT NULL,
  gateway TEXT NOT NULL,
  gateway_transaction_id TEXT,
  amount INTEGER NOT NULL,  -- 金额（分）
  currency TEXT NOT NULL DEFAULT 'TWD',
  payment_method TEXT NOT NULL,
  status TEXT NOT NULL,     -- pending, processing, success, failed, expired, refunded, cancelled
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL,
  paid_at TEXT,
  expired_at TEXT
);

-- 支付回调日志表
CREATE TABLE payment_callbacks (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  transaction_id TEXT NOT NULL,
  gateway TEXT NOT NULL,
  callback_data TEXT NOT NULL,
  status TEXT NOT NULL,
  error_message TEXT,
  created_at TEXT NOT NULL
);

-- 退款记录表
CREATE TABLE payment_refunds (
  id TEXT PRIMARY KEY,
  transaction_id TEXT NOT NULL,
  amount INTEGER NOT NULL,
  reason TEXT,
  status TEXT NOT NULL,     -- pending, success, failed
  gateway_refund_id TEXT,
  created_at TEXT NOT NULL,
  processed_at TEXT
);

-- 安全日志表
CREATE TABLE payment_security_logs (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  event_type TEXT NOT NULL,
  gateway TEXT,
  ip_address TEXT,
  user_agent TEXT,
  request_data TEXT,
  created_at TEXT NOT NULL
);

-- 索引
CREATE INDEX idx_payment_transactions_order_id ON payment_transactions(order_id);
CREATE INDEX idx_payment_transactions_status ON payment_transactions(status);
CREATE INDEX idx_payment_callbacks_transaction_id ON payment_callbacks(transaction_id);
```

## 常见问题

### Q1: 如何切换测试/生产环境？

修改 `wrangler.toml` 中的 `PAYMENT_ENVIRONMENT`：
- `"test"` - 使用测试商户号和测试 API 地址
- `"production"` - 使用生产商户号和生产 API 地址

### Q2: 回调地址如何配置？

确保蓝新金流后台的 **NotifyURL** 设置为：
```
https://your-api.com/api/payment/callback/newebpay
```

### Q3: 密钥长度不符合要求？

蓝新金流要求：
- HashKey: 16 或 32 位字符
- HashIV: 16 或 32 位字符

如密钥长度不符，需在蓝新后台重新生成。

### Q4: 如何启用特定支付方式？

在蓝新金流商家后台：
1. 进入「信用卡收单」或「超商代收」设置
2. 启用所需的支付方式
3. 设置手续费和结算周期
